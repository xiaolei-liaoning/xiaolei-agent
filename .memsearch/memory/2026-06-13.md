- User asked what LSP (Language Server Protocol) is.
- OpenCode explained LSP is an open protocol from Microsoft that enables editors like VS Code, Neovim, and Emacs to provide smart code features (autocomplete, go-to-definition, hover type hints, diagnostics, refactoring/rename) via a language server.
- OpenCode noted that editors only need to implement an LSP client, and language authors write one LSP server to support all editors, citing examples like pyright, typescript-language-server, and rust-analyzer.
