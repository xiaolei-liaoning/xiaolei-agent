## 二、双架构并存：V1 vs V2

### V1 架构 (`core/agent_system.py`, 65 个符号)

| 特性 | 说明 |
|------|------|
| **入口** | `core/agent_system.py` → `AgentSystem` 类 |
| **数据流** | 用户输入 → SkillDispatcher → AgentSystem.execute → 单轮 LLM 调用 |
| **工具系统** | `core/tools/` — bash_tool, shell_executor, sandbox_executor 等 |
| **记忆系统** | `core/memory/` — short_term_memory, vector_memory, user_profile |
| **多步任务** | `core/handlers/multi_step_handler.py` + `core/workflow/bfs_processor.py` |
| **状态** | 完整可用，被测试覆盖 |

### V2 架构 (`core/multi_agent_v2/`, 大量模块)

| 特性 | 说明 |
|------|------|
| **入口** | `cli/smart_agent_v2.py` → `SmartAgentCLIv2` |
| **Agent 实现** | `WorkAgent` → 统一的 `execute()` → `run_react()` (ReActCore) |
| **中间件链** | `middleware.py` + `memory_middleware.py` + 14 层中间件 |
| **编排引擎** | `orchestration/orchestrator.py` — `agent()` / `parallel()` / `pipeline()` |
| **工具注册表** | `tools/tool_registry.py` — 统一注册、查询、权限 |
| **工作流** | `workflow/` — js_workflow, subagent, command, discovery |
| **状态** | 活跃开发，CLI 默认使用 |

### 核心数据流（V2，当前主路径）

```
用户输入 → REPL → EnhancedCLI.handle_command()
                    → ChatHandler.handle_smart_request()
                      → SmartAgentCLIv2.handle_task_with_steps()
                        → Orchestrator.agent()
                          → WorkAgent.execute()
                            1. Skill 三层匹配 (base_skills.py)
                              ├─ Layer 1: 8 个 BaseSkill (agents.yml)
                              ├─ Layer 2: 216 个 Expert Persona (agency_agents/)
                              └─ Layer 3: Guidance Skill 指导内容
                            2. ReActCore.run_react()
                              ├─ 中间件链验证(权限/记忆/预算)
                              └─ 循环: 思考→工具调用→观察→直到完成
```

## 三、Skill/Agent 系统详解

### 三层匹配（`core/skills/base_skills.py`）

```
用户请求 → SkillSystem.match()
  Layer 1: 从 8 个 BaseSkill 中根据关键词匹配
    ├─ project_analyzer (3 tools, pri=3)
    ├─ general (2 tools, pri=1)
    ├─ data_analyst (3 tools, pri=3)
    ├─ web_scraper (9 tools, pri=4)
    ├─ weather_expert (1 tool, pri=2)
    ├─ system_toolbox (2 tools, pri=2)
    ├─ translator (1 tool, pri=2)
    ├─ deep_thinker (3 tools, pri=5)
    └─ creative (3 tools, pri=2)

  Layer 2: 在对应的 Expert 分类中匹配 216 个角色
    └─ 分类: engineering, marketing, design, finance, ...

  Layer 3: 从 guidance_skills 加载 SKILL.md 指导内容
```

### Skill MCP 服务器 (`mcp/skill_mcp_server.py`)

- **模式**: stdio MCP 协议
- **技能来源**: `~/.opencode/ecc-skills/` + 本地 `core/skills/`
- **暴露工具**: `skill_list`, `skill_get`, `skill_search`, `skill_execute`, `skill_agent_run`
- **分类**: product, frontend, backend, content, media, ai, devops, 等 11 类

### 意图路由（`config/`）

| 配置 | 作用 |
|------|------|
| `skill_keywords.yaml` | 20 个技能的 300+ 关键词匹配规则 |
| `agents.yml` | 9 个 Base Agent 的角色提示词 + 工具绑定 |

## 五、记忆系统层级

```
L0: Tool Result Budget   — 控制工具输出字符数（截断）
L1a: API Context Mgmt    — API 响应上下文管理
L1b: Collapse Read/Search— 折叠重复读写
L1c: Time-based MC       — 基于时间的微压缩
L2: Cached MicroCompact  — 缓存微压缩
L2b: Snip Compact        — 截断式压缩
L3: LLM Compaction       — LLM 重新摘要
L4: Post Compact Rebuild — 压缩后重建

Vector Memory:           — 语义向量检索
Short Term Memory:       — 短期对话记忆
Conversation History:    — 完整对话历史
User Profile:            — 用户画像
Memory Middleware:       — V2 中间件链中的记忆管理
React Compact:           — ReAct 轮次的压缩
Memory Optimizer:        — 记忆优化器（含 token 计数）
```

## 六、请求处理完整路径

```
用户输入 "搜索百度热搜并生成报告"
↓
EnhancedCLI.handle_command()
  ├─ 检测到非命令 → ChatHandler.handle_smart_request()
↓
SmartAgentCLIv2.handle_task_with_steps()
  ├─ 估算步骤数 → 生成 3 步模板 (分析→执行→验证)
  └─ 顺序 orchestrator.agent()
↓
Orchestrator.agent(prompt, opts)
  └─ WorkAgent.execute()
↓
WorkAgent.execute():
  1. 项目分析检测 → Phase 1+2 扫描
  2. Skill 三层匹配 → 注入 role_prompt + Expert + Guidance
  3. skill_agent_map 覆盖检查
  4. run_react() → ReActCore
↓
ReActCore.run_react():
  ├─ 中间件链: 权限 → 记忆 → 预算
  ├─ ReAct 循环: 思考→工具选择→执行→观察
  │  └─ ToolExecutor → 工具注册表 → MCP 调用
  └─ 返回 {success, answer, error, rounds}
```
