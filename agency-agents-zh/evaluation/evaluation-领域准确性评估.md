================================================================================
提示词名称: 领域准确性评估
描述: 框架，用于评估 AI 输出是否准确遵循领域特定知识、标准和最佳实践。
使用场景:
  - 验证生成代码的技术准确性
  - 检查是否符合行业标准
  - 验证框架特定约定
  - 评估领域专业知识质量
================================================================================

<evaluation_dimensions>
技术正确性:
- 语法有效性
- 类型安全
- 逻辑正确性
- 算法适当性
- API 使用正确性

框架约定:
- 遵循框架模式
- 使用惯用代码
- 遵循框架生命周期
- 正确的依赖注入
- 正确的配置

行业标准:
- 遵循语言风格指南
- 遵循设计模式
- 实施安全最佳实践
- 满足无障碍标准
- 遵守法规（GDPR 等）

领域知识:
- 使用正确的术语
- 应用领域模式
- 理解业务规则
- 识别边界情况
- 了解常见陷阱
</evaluation_dimensions>

<accuracy_scoring>
评分（0-10）:
10: 完美的领域准确性，专家级别
8-9: 高度准确，有轻微差距
6-7: 基本准确，有一些错误
4-5: 多处不准确
2-3: 严重的领域错误
0-1: 根本性错误

评估标准:
- 领域专家会认可这个吗？
- 它遵循已建立的模式吗？
- 有危险的错误吗？
- 术语使用正确吗？
- 边界情况处理得当吗？
</accuracy_scoring>

<domain_specific_checks>
Web 开发:
- 正确的 HTTP 方法（GET 用于读取，POST 用于创建）
- 正确的状态码（200、201、400、404、500）
- CORS 配置
- 安全头
- RESTful 设计原则

React/前端:
- 正确的 hook 使用（hooks 规则）
- 组件生命周期理解
- 状态管理模式
- 性能优化
- 无障碍属性

数据库:
- 正确的索引策略
- 事务处理
- N+1 查询预防
- 数据规范化
- 约束使用

安全:
- 输入验证
- 输出编码
- 身份验证/授权
- 安全密码处理
- HTTPS 强制
</domain_specific_checks>
