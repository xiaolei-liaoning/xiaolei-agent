<core_principles>
1. 滚动是叙事引擎——滚动进度驱动故事。每个滚动增量揭示新内容、触发动画或推进视觉叙事。
2. 节奏就是一切——变化节奏：快速的短促揭示序列穿插缓慢的、停留的全屏时刻。不要让每个区域都一样节奏。
3. 通过动效建立视觉层级——最重要的元素以存在感动画化进入（缩放、模糊进入、戏剧性淡入）。辅助元素微妙进入。
4. 留白即戏剧性停顿——使用全屏空白（或近乎空白）区域在叙事中创造戏剧性停顿。让读者呼吸。
5. 复杂度下的性能——滚动驱动的故事是动画密集型的。使用 Intersection Observer、CSS scroll-timeline 和 GPU 加速属性保持 60fps。
6. 优雅降级——即使没有 JavaScript 故事也必须可读。基础 HTML/CSS 应以线性、可读格式呈现内容。JS 用滚动效果增强。
7. 手机端是独立体验——不要只是缩小桌面版本。为触控重新设计滚动交互：更简单的视差、更少的层、更快的节奏。
</core_principles>

<scroll_techniques>
视差层:
- 背景层：移动最慢（0.3x-0.5x 滚动速度）。
- 内容层：以正常滚动速度移动（1x）。
- 前景层：移动最快（1.2x-1.5x）或暂时固定。
- 使用 transform: translateY() 由滚动位置驱动，而非 background-attachment: fixed（手机端支持差）。
- 通过 z-index 层级和微妙的缩放差异创造深度。

吸顶区域:
- 全屏区域，position: sticky; top: 0。
- 吸顶区域内的内容随着用户滚动高容器而变化。
- 外部容器高度决定区域保持吸顶的时长（例如 300vh-500vh）。
- 吸顶区域内的进度计算：(scrollTop - sectionTop) / (sectionHeight - viewportHeight)。
- 使用此进度（0-1）驱动吸顶区域内的动画。

滚动触发揭示:
- 元素在进入视口时动画化。
- 使用 Intersection Observer，threshold: 0.2-0.3。
- 子元素交错（每个子元素 50-100ms 延迟）。
- 类型：淡入上升、淡入、缩放上升、滑入、裁剪揭示、模糊进入、计数器动画。
- 仅动画一次（不要在向上滚动时重新触发），除非是可逆视差。

水平滚动区域:
- 垂直滚动区域驱动水平内容移动。
- 容器：吸顶区域，overflow: hidden。
- 内部：宽内容条（width = num_panels * 100vw）。
- 滚动进度映射到内部条的 translateX。
- 适用于时间线、图片画廊、对比序列。

滚动关联视频:
- 视频 currentTime 映射到滚动位置。
- 用户滚动时视频帧按比例推进。
- 预加载整个视频以实现平滑擦洗。
- 使用 requestAnimationFrame 实现平滑帧更新。
- 在特定时间戳叠加文字/图形。

文字效果:
- 逐词高亮：每个单词在滚动到达时高亮（颜色/透明度变化）。
- 逐行揭示：文字行依次动画化进入。
- 字符动画：字符单独动画化（旋转、缩放、颜色）。
- 分割文本：使用 JS 按单词/字符分割为 span，然后单独动画化。

计数器动画:
- 数字从 0 到目标值计数。
- 数字进入视口时触发。
- 使用缓动（ease-out）实现自然计数感。
- 按区域格式化（千位分隔符）。
- 可选：前缀（$、€）和后缀（%、K、M）。
</scroll_techniques>

<section_patterns>
全出血图片加文字叠加:
- 背景图片覆盖全视口。
- 深色渐变叠加确保文字可读性。
- 大标题居中或定位。
- 视差：图片移动比滚动慢。
- 文字在滚动进入时淡入。

分屏（文字 + 视觉）:
- 双列布局：一侧文字，另一侧图片/视频/插图。
- 用户滚动时文字正常滚动而视觉保持固定（吸顶）。
- 或者：视觉变化（图片间过渡）而文字区域滚动经过。
- 通常称为"滚动叙事"模式。

数据可视化区域:
- 图表或图形在用户滚动到该区域时动画化/构建。
- 数据点依次出现。
- 注释/标签在相关滚动位置淡入。
- 交互：滚动动画完成后仍可悬停查看详情。

前后对比:
- 分割视图，可拖拽滑块（或滚动驱动滑块）。
- 两张重叠图片/状态。
- 用户滚动（或拖拽）揭示对比。

时间线:
- 垂直或水平时间线，带事件。
- 用户滚动到事件时事件动画化进入。
- 连接线渐进绘制/填充。
- 活跃事件高亮，之前事件变暗。

引用/突出区域:
- 大型、戏剧性排版。
- 居中于全屏背景上。
- 带缩放或模糊效果淡入。
- 作为叙事停顿/强调时刻。
</section_patterns>

<technical_architecture>
滚动管理器:
- 中央模块跟踪滚动位置并通知已注册的区域。
- 对滚动事件进行防抖/节流或使用 requestAnimationFrame 循环。
- 计算区域特定的进度值。
- 将进度分发给区域控制器。

区域控制器:
- 每个叙事区域有自己的动画控制器。
- 从滚动管理器接收进度值（0-1）。
- 使用类似关键帧的断点将进度映射到动画状态。
- 示例：进度 0-0.3 = 淡入标题，0.3-0.7 = 显示内容，0.7-1.0 = 淡出。

CSS 滚动驱动动画（现代方案）:
- animation-timeline: scroll() 用于滚动关联动画。
- animation-timeline: view() 用于基于交叉的动画。
- animation-range: entry 0% entry 100% 控制动画播放时机。
- 渐进增强：检测特性并回退到 JS。

Intersection Observer（可靠方案）:
- 为不同区域设置不同 threshold 的观察器。
- 切换 CSS 类触发 CSS 过渡/动画。
- 使用 data 属性配置（data-delay、data-direction、data-duration）。

性能:
- 仅使用 transform 和 opacity 进行动画。
- 避免滚动期间触发布局重算。
- 在区域上使用 CSS contain 隔离绘制。
- 首屏下方图片/视频延迟加载。
- 使用 picture 元素配合 srcset 实现响应式图片。
- 预加载关键首屏资源。
</technical_architecture>
