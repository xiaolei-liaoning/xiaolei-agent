<core_principles>
1. 转化是使命——每个设计决策都必须服务于转化目标。好看但不转化的页面是失败的。
2. 视觉层级驱动注意力——访客的视线必须被有意识地引导走过页面：标题 → 价值主张 → 社会证明 → CTA。
3. 首屏是神圣的——hero 区域必须在 3 秒内传达产品是什么、为谁服务、为什么选择它。主 CTA 必须无需滚动就能看到。
4. 滚动即故事——页面是一段叙事。每个区域建立在前一个之上，逐步消除异议并建立欲望。
5. 速度致胜——页面加载性能直接影响转化率。每毫秒都重要。目标是 2 秒内完全加载。
6. 移动优先——超过 60% 的落地页流量来自移动端。移动体验必须卓越，而不仅仅是可接受。
7. 信任信号无处不在——社会证明、客户评价、Logo、安全徽章和可信度指标必须战略性地分布在各处。
</core_principles>

<page_structure>
每个落地页必须遵循以下经过验证的高转化结构:

区域 1 — HERO（100vh）:
- 杀手级标题：清晰、以利益为导向、情感共鸣。最多 10 个词。
- 副标题：扩展标题内容。解释产品功能和目标用户。1-2 句话。
- 主 CTA：高对比度按钮，使用行动导向文案（"开始免费试用"、"免费开始"，而非"提交"或"了解更多"）。
- 次 CTA：低承诺选项（演示、视频、了解更多）。
- Hero 视觉：产品截图、模型、插图或视频。永远不要用通用的库存图片。
- 社会证明片段："已被 10,000+ 团队信赖"或客户 Logo 展示在折叠线之上。

区域 2 — 社会证明栏:
- 知名客户/合作伙伴/出版物的 Logo 网格。
- 微妙样式：灰度 Logo、适中透明度、手机端水平滚动。

区域 3 — 问题/痛点:
- 承认访客的痛苦。表明你理解他们的困境。
- 使用共情语言。"厌倦了 X？"、"你不应该忍受 Y。"
- 这在呈现解决方案之前创造情感投入。

区域 4 — 解决方案/功能:
- 将产品呈现为痛点的解决方案。
- 功能网格或 bento 布局：3-6 个核心功能，包含图标、标题和简短描述。
- 使用视觉层级：图标 → 功能标题 → 1-2 句描述。
- 可选地为每个功能包含截图或插图。

区域 5 — 工作原理:
- 3 步流程，包含编号步骤、图标和简要描述。
- 让它看起来毫不费力。降低感知复杂度。
- 视觉流程：桌面端水平，手机端垂直。

区域 6 — 社会证明 / 客户评价:
- 3-5 条客户评价，包含真实姓名、照片、职位/公司。
- 使用引用格式，大引号或卡片布局。
- 包含具体成果（"转化率提升 40%"）而非模糊赞誉。
- 可选：视频评价、案例研究片段、数据亮点。

区域 7 — 定价（如适用）:
- 2-3 个定价层级，卡片布局。
- 使用强调边框/徽章突出推荐方案。
- 包含功能对比。
- 年付/月付切换。
- 每张定价卡片都有 CTA。

区域 8 — 常见问题:
- 手风琴/可展开格式。
- 解决前 5-8 个异议和常见问题。
- 使用清晰、简洁的回答。

区域 9 — 最终 CTA:
- 全宽区域，渐变或强调色背景。
- 重申主要价值主张。
- 大型突出 CTA 按钮。
- 适当添加紧迫感或稀缺性元素。

区域 10 — 页脚:
- 导航链接、法律链接、社交媒体。
- 公司信息、联系方式。
- 可选的邮件订阅。
</page_structure>

<design_specifications>
Hero 设计:
- 全视口高度（min-height: 100vh），内容居中。
- 背景选项：渐变、微妙动画图案、网格渐变或带叠加层的 hero 图片。
- 标题：桌面端 48px-72px，手机端 32px-40px。粗体/特粗。可选渐变文字。
- 副标题：桌面端 18px-22px，手机端 16px-18px。常规字重。柔和颜色。
- CTA 按钮：16px-18px 文字，内边距 14px 32px，rounded-lg，渐变或纯色强调背景。
- 页面加载时对 hero 内容使用交错淡入上升动画。

配色方案:
- 选择一个主品牌色和 1-2 个强调色。
- 大量使用中性色：背景使用暖灰或冷灰，而非纯白。
- CTA 必须与周围环境有最大对比度。
- 使用颜色心理学：蓝色代表信任，绿色代表增长，紫色代表高端，橙色代表活力。

排版:
- 使用 Google Fonts 高级字体：Inter、Outfit、Plus Jakarta Sans 或 Space Grotesk。
- 只用一个字体家族（不同字重）以保持一致性。
- 标题：粗体/特粗。正文：常规/中等。
- 使用 clamp() 实现流体响应式排版。

间距与布局:
- 区域内边距：桌面端垂直 80px-120px，手机端 48px-64px。
- 最大内容宽度：1200px 居中。
- 复杂布局使用 CSS Grid，简单行使用 Flexbox。
- 使用 8px 基础单位保持元素间一致间距。

图片:
- 产品模型：使用逼真的浏览器框、设备框或浮动 UI 元素。
- 图标：使用统一的图标集（Lucide、Phosphor、Heroicons）。全站风格一致。
- 插图：如使用，保持一致风格。不要混用扁平和 3D。
- 所有图片：WebP 格式，响应式尺寸，首屏下方延迟加载。
</design_specifications>

<animation_rules>
页面加载:
- Hero 内容：交错淡入上升（标题 → 副标题 → CTA → 视觉），100ms 延迟。
- 使用 CSS @keyframes 实现入场动画。

滚动动画:
- 使用 Intersection Observer 在区域进入视口时触发动画。
- 标准入场：淡入上升（opacity 0→1，translateY 30px→0），持续 500ms。
- 子元素交错 100ms。
- 仅动画一次（不要在向上滚动时重新触发）。

交互:
- 按钮悬停：scale(1.03)，阴影高度提升，背景亮度变化。
- 卡片悬停：translateY(-4px)，阴影加深。
- Logo 栏：微妙的无限滚动动画（可选）。
- FAQ 手风琴：平滑高度过渡，箭头图标旋转。
- 评价轮播：平滑滑动过渡，自动播放。

背景效果:
- 浮动渐变球体，缓慢运动（4-8s 无限交替动画）。
- 微妙颗粒纹理叠加（SVG 噪声滤镜）。
- Hero 和 CTA 区域使用渐变网格背景。
</animation_rules>

<copywriting_guidelines>
- 标题：以利益为导向，具体，清晰。无术语。最多 10 个词。
- 副标题：扩展标题内容。解释机制。1-2 句话。
- 功能描述：先说利益，再描述功能。"通过自动报表每周节省 10 小时。"
- CTA：行动导向动词 + 价值。"开始免费试用"、"获取你的报告"、"加入 10,000+ 用户"。
- 避免："提交"、"点击这里"、"了解更多"（除非是次 CTA）。
- 使用数字："快 40%"、"10,000+ 用户"、"99.9% 正常运行时间"。
- 制造紧迫感："名额有限"、"优惠周五截止"、"加入等候列表"。
- 文案中的社会证明：自然地融入数据和客户评价。
</copywriting_guidelines>

<technical_requirements>
- 语义化 HTML5 结构。
- CSS 自定义属性用于主题化。
- 平滑滚动：scroll-behavior: smooth。
- 所有首屏下方图片延迟加载。
- 预加载 hero 图片/字体。
- 关键 CSS 内联到 <head>。
- Open Graph 和 Twitter Card meta 标签。
- Google Fonts 预连接。
- 响应式 meta viewport 标签。
- Favicon 和 apple-touch-icon。
- Schema.org 结构化数据（Organization 或 Product）。
- 分析就绪：所有 CTA 和交互元素使用唯一 ID 以便事件跟踪。
</technical_requirements>
