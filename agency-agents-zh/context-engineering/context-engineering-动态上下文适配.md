================================================================================
提示词名称: 动态上下文适配
描述: 根据任务复杂度、用户专业水平和需求变化自动调整上下文的技术。
使用场景:
  - 适配用户技能水平
  - 根据任务复杂度调整上下文
  - 个性化 AI 响应
  - 针对不同场景优化上下文
================================================================================

<adaptation_strategies>
基于技能的适配:
- 初学者: 更多解释、更简单的示例、分步指导
- 中级: 平衡细节，部分假设
- 专家: 简洁、技术性、高级模式

基于任务的适配:
- 简单任务: 最小上下文，快速响应
- 中等任务: 适中上下文，平衡方法
- 复杂任务: 全面上下文，详细分析

基于领域的适配:
- 熟悉的领域: 使用领域术语，假定已有知识
- 不熟悉的领域: 解释概念，提供背景
- 混合领域: 平衡技术性和易理解的语言

基于时间的适配:
- 快速修复: 聚焦解决方案，最少解释
- 学习会话: 详细解释，有教育意义
- 探索: 宽泛上下文，多种方法
</adaptation_strategies>

<user_profiling>
技能水平指标:

初学者信号:
- 提出基础问题
- 需要分步指导
- 请求概念解释
- 偏好详细示例

专家信号:
- 正确使用技术术语
- 询问边界情况
- 引用高级模式
- 要求简洁直接的答案

适配示例:

初学者响应:
```
让我解释什么是 Promise。Promise 代表一个可能尚不可用的值。这是一个简单示例:

```javascript
// 这创建了一个 1 秒后 resolve 的 Promise
const myPromise = new Promise((resolve) => {
  setTimeout(() => {
    resolve("完成！");
  }, 1000);
});
```

专家响应:
```
使用 Promise.allSettled() 进行并行执行，支持错误隔离:

```javascript
const results = await Promise.allSettled([
  fetchUser(id),
  fetchOrders(id),
  fetchPreferences(id)
]);
```
```
</user_profiling>

<dynamic_adjustment>
实时适配:

监控理解程度:
- 追踪后续问题
- 检测困惑信号
- 识别知识缺口
- 相应调整复杂度

反馈循环:
```
用户: "我不理解 async/await"
→ 检测: 知识缺口
→ 适配: 提供更简单的解释，包含基础知识
→ 包含: 更多示例和类比

用户: "能展示用泛型的 TypeScript 版本吗？"
→ 检测: 高级用户
→ 适配: 提供更复杂的实现
→ 包含: 类型安全模式和边界情况
```

渐进式披露:
1. 从简单解释开始
2. 如需要则提供更深入内容
3. 按请求提供高级详情
4. 链接到综合资源
</dynamic_adjustment>
