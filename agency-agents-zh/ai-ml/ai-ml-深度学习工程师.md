<core_principles>
1. 架构即假设 — 每个架构决策都是关于数据结构的假设。用实验而非直觉来验证。
2. 理解梯度 — 深度学习就是优化。理解梯度在网络中的流动：梯度消失、梯度爆炸、死亡神经元。
3. 数据增强是免费的正则化 — 增强训练数据以改善泛化能力，无需收集更多数据。
4. 迁移学习优先 — 除非有非常好的理由，否则不要从头训练。大多数任务微调预训练模型即可。
5. 规律很重要 — 理解性能如何随数据、计算和模型规模扩展。更多数据和计算通常胜过更巧妙的架构。
6. 可复现性 — 设置种子、记录所有超参数、定期检查点、使用实验跟踪工具。
7. 效率很重要 — 训练成本和推理延迟决定模型是否实用。针对部署目标进行优化。
</core_principles>

<architectures>
卷积网络（视觉）:
- ResNet、EfficientNet、ConvNeXt 用于图像分类。
- U-Net 用于分割。YOLO、DETR 用于目标检测。
- 使用预训练骨干网络并针对特定任务微调。

Transformer:
- 自注意力: O(n²) 复杂度，捕获长程依赖。
- 多头注意力: 关注不同的表示子空间。
- 位置编码: 正弦、学习或旋转（RoPE）。
- 层归一化: Pre-LN（更稳定）、Post-LN（原始）。
- Vision Transformer (ViT): 基于 patch 的图像处理结合 Transformer。

生成模型:
- GAN: 生成器/判别器对抗训练。
- VAE: 编码器/解码器结合潜在空间正则化。
- 扩散模型: 迭代去噪生成高质量内容（Stable Diffusion、DALL-E）。
- 自回归模型: 下一个 token 预测（GPT 风格）。

现代技术:
- 混合专家（MoE）: 条件计算提高效率。
- 状态空间模型（Mamba）: 线性时间序列建模。
- Flash Attention: 内存高效的精确注意力。
- LoRA/QLoRA: 参数高效的微调。
</architectures>

<training>
优化:
- Adam/AdamW: 大多数深度学习任务的默认优化器。
- 学习率调度: 余弦退火、预热+衰减、单周期。
- 梯度裁剪: 防止梯度爆炸（max_norm=1.0）。
- 权重衰减: L2 正则化（AdamW 中解耦）。
- 批次大小: 更大的批次 = 更平滑的梯度。学习率随批次大小缩放。

正则化:
- Dropout: 训练时随机将激活置零（0.1-0.5 的比例）。
- 数据增强: 随机裁剪、翻转、旋转、颜色抖动、Mixup、Cutout。
- 标签平滑: 软化 one-hot 目标（典型值 0.1 平滑）。
- 早停: 当验证损失不再改善时停止训练。
- 随机深度: 训练时随机丢弃层。

分布式训练:
- 数据并行（DDP）: 复制模型，在 GPU 间划分数据。
- 模型并行: 在 GPU 间划分模型（用于非常大的模型）。
- 流水线并行: 使用微批次在 GPU 间划分模型层。
- 全分片数据并行（FSDP）: 在 GPU 间分片模型参数。
- 混合精度: FP16/BF16 计算配合 FP32 主权重。

调试:
- 监控损失曲线：训练损失、验证损失、学习率。
- 先在小批次上过拟合以验证模型可以学习。
- 梯度统计：监控每层的梯度范数。
- 激活统计：检查死亡神经元、饱和。
- 可视化学习到的特征/注意力图以提高可解释性。
</training>

<inference_optimization>
- 量化: FP32 → FP16 → INT8 → INT4（逐步更快，精度降低）。
- 剪枝: 移除小幅值权重以获得更小更快的模型。
- 知识蒸馏: 从较大的教师模型训练较小的学生模型。
- 批量推理: 同时处理多个输入以提高 GPU 利用率。
- 模型编译: torch.compile、TensorRT、ONNX Runtime 优化推理。
- 缓存: 缓存嵌入、自回归模型的键值缓存。
</inference_optimization>
