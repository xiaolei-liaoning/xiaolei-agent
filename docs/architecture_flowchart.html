💭 图3: LLM反思机制流程
flowchart TD
    START([开始执行]) --> STEP1[执行当前步骤]

    STEP1 --> CHECK1{成功？}
    CHECK1 -->|否| TRIGGER1[触发反思]
    CHECK1 -->|是| CHECK2{超时？}

    CHECK2 -->|是| TRIGGER2[触发反思]
    CHECK2 -->|否| CHECK3{置信度<阈值？}

    CHECK3 -->|是| TRIGGER3[触发反思]
    CHECK3 -->|否| CHECK4{周期性检查？}

    CHECK4 -->|是| TRIGGER4[触发反思]
    CHECK4 -->|否| CONTINUE[继续下一步]

    TRIGGER1 --> REFLECT[LLM反思]
    TRIGGER2 --> REFLECT
    TRIGGER3 --> REFLECT
    TRIGGER4 --> REFLECT

    REFLECT --> DECISION{决策}

    DECISION -->|CONTINUE| CONTINUE
    DECISION -->|RETRY| RETRY[重试上一步]
    RETRY --> STEP1
    DECISION -->|SKIP| SKIP[跳过下一步]
    SKIP --> NEXT[跳到下下步]
    DECISION -->|ADD| ADD[添加新步骤]
    ADD --> STEP1
    DECISION -->|FAIL| FAIL([宣告失败])

    CONTINUE --> DONE{所有步骤完成？}
    DONE -->|否| STEP1
    DONE -->|是| FINAL[聚合结果]

    style TRIGGER3 fill:#ffcdd2,stroke:#d32f2f
    style TRIGGER4 fill:#ffcdd2,stroke:#d32f2f
    style REFLECT fill:#fff9c4,stroke:#f9a825
    style FAIL fill:#f44336,stroke:#b71c1c
🧠 图4: 意图理解流程
flowchart TB
    INPUT[用户输入文本] --> EXTRACT[实体提取]
    EXTRACT --> RULE[基于规则的意图分类]
    RULE --> CONF1{置信度>阈值？}

    CONF1 -->|否| LLM[LLM辅助分类]
    LLM --> CONF2{有LLM？}
    CONF2 -->|是| USELLM[使用LLM分类]
    USELLM --> INTENT[最终意图]
    CONF2 -->|否| FALLBACK[回退到规则]
    FALLBACK --> INTENT

    CONF1 -->|是| INTENT

    INTENT --> CONSTRAINT[约束识别]
    CONSTRAINT --> KEYWORD[关键词提取]
    KEYWORD --> COMPLEXITY[复杂度评估]
    COMPLEXITY --> OUTPUT[结构化任务定义]

    subgraph 意图类型
        I1[QUERY 查询]
        I2[ACTION 执行]
        I3[CREATION 创建]
        I4[ANALYSIS 分析]
        I5[MODIFICATION 修改]
        I6[DELETION 删除]
    end

🔄 图5: 任务生命周期
stateDiagram-v2
    [*] --> PENDING: 创建任务

    PENDING --> PARSING: 进入调度器
    PARSING --> DECOMPOSING: 意图理解完成
    DECOMPOSING --> SCHEDULING: 分解完成

    SCHEDULING --> ASSIGNING: 选择Agent
    ASSIGNING --> EXECUTING: 任务分配

    EXECUTING --> REFLECTING: 步骤完成
    REFLECTING --> DECIDING: 反思完成

    DECIDING --> CONTINUE: 继续执行
    DECIDING --> RETRY: 重试
    DECIDING --> SKIP: 跳过
    DECIDING --> FAIL: 失败

    CONTINUE --> EXECUTING: 下一步
    RETRY --> EXECUTING: 重试当前
    SKIP --> EXECUTING: 跳过当前

    EXECUTING --> AGGREGATING: 所有步骤完成
    AGGREGATING --> COMPLETED: 聚合完成

    FAIL --> CANCELLED: 任务取消
    COMPLETED --> [*]

    note right of PENDING: 等待调度
    note right of EXECUTING: Agent执行中
    note right of REFLECTING: LLM评估质量
    note right of AGGREGATING: 结果汇总
