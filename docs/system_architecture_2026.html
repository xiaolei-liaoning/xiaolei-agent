📐 架构设计原则

  1. Simplicity First：优先使用轨道1（SkillDispatcher），仅在复杂场景启用轨道2/3
  2. 双轨制：XML工作流处理确定性任务，Agency Agent处理探索性任务
  3. 统一注册表：所有轨道共享ToolRegistry/SkillRegistry
  4. 渐进式演进：从简单到复杂，按需升级执行路径
