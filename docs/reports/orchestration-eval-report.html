🔍 关键发现

✅ 8 个正确行为

  1. parallel 优先级高于 \$dag — 改版后 5/10 用了 parallel（改前 1/10），\$dag 从 7/10 降到 1/10。LLM 学会了"先想 parallel，复杂拓扑才用 \$dag"。
  2. 模型分配合理 — 简单任务自动 haiku，复杂任务用 sonnet。
  3. phase() 全覆盖 — 10/10 正确使用，且 meta.phases 与代码一一对应。
  4. label 全覆盖 — 所有 agent 调用有可读 label。
  5. 容错写法标准 — .catch() + return null + filter(Boolean)。
  6. while 含保护 — MAX_ROUNDS 上限 + 超限 log 报警。
  7. 代码类不再硬编码 \$dag — 代码任务也用 parallel 和 while。
  8. 空列表友好处理 — 不崩溃，返回提示。

⚡ 2 个可继续优化

  1. 条件语义判断 — if 分支用字符串 contains 而非 agent 语义判断。可加提示："让 agent 做语义判断而非字符串匹配"。
  2. 辅助 agent 可精简 — 有些两步可合并为一步。微小代价。
